# Chepkumia Joyland Academy

This is a static school website.

## Local preview

Open `index.html` in a browser, or use a local preview tool such as Live Server.

## Live deployment

This project includes a GitHub Pages workflow. After pushing to the `main` branch and enabling GitHub Pages in the repository settings, the site will be published at:

https://<your-github-username>.github.io/<your-repository-name>/
